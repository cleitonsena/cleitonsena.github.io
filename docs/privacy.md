# Privacy Policy

**Toffee Tabby Pin Publisher**. Effective date: 23 November 2026.

This policy covers Toffee Tabby Pin Publisher, a private script run by Cleiton Sena (the owner of the Toffee Tabby coloring book collection). It is not a public app and has no other users.

## What the app does

The app publishes pins for my own coloring books to my own Pinterest business account, and reads my own boards to choose where each pin goes. It is used only by me, on my own computer, with my own Pinterest account.

## What data it uses

- **Pinterest account data:** the list of my own boards and the pins the app creates. Nothing from any other Pinterest user is accessed.
- **Access token:** the OAuth token Pinterest gives after I sign in. It is stored only on my own computer, in a file readable only by my user account. It is never shared, published or sent anywhere except to the Pinterest API.

## What it does not do

- It does not collect, store or process personal data of other people.
- It does not use cookies, analytics or tracking.
- It does not sell, rent or share any data with third parties.
- It does not store Pinterest passwords. Sign-in happens on Pinterest through the official OAuth flow.

## Retention and deletion

Pin and board data stays on Pinterest under my account. The access token is deleted from my computer when the app is no longer used. Access can be revoked at any time in Pinterest settings under connected apps.

## Changes

If this policy changes, the new version will be published on this page with a new effective date.
